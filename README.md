# مكتبة الأوصاف الوظيفية

نظام داخلي لإدارة وعرض الأوصاف الوظيفية للموظفين والإدارة والموارد البشرية.

## المزايا
- تصميم عربي RTL بألوان دافئة مع الأزرق الداكن والذهبي.
- بحث وفرز وتصنيف حسب الإدارة والقسم.
- إضافة وتعديل وحذف الوظائف.
- صفحة تفصيلية لكل وصف وظيفي.
- طباعة الوصف وحفظه PDF من نافذة الطباعة.
- حفظ البيانات محليًا في المتصفح.
- تصدير واستيراد البيانات بصيغة JSON لنقل المكتبة بين الأجهزة.

## التشغيل
افتح index.html في المتصفح، أو استضف الملفات على GitHub Pages أو أي استضافة ملفات ثابتة.

## ملاحظة
الحفظ الحالي محلي للمتصفح. إذا أردت أن تصبح الإضافة والتعديل والحذف مشتركة وفورية بين جميع أجهزة الشركة، يمكن ربط المشروع لاحقًا بقاعدة بيانات مركزية مثل Supabase.
