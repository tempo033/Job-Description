# مكتبة الأوصاف الوظيفية لشركات المقاولات

مكتبة HR داخلية تحتوي على **118 وظيفة موزعة على 15 قسمًا**، مخصصة لوصف الوظائف الحالية داخل الشركة، وليست نظام توظيف.

## الأقسام
الإدارة العليا، الموارد البشرية، الإدارة الهندسية، المكتب الفني، إدارة التشغيل، المشتريات وسلسلة الإمداد، المستودعات والمخزون، إدارة العقود، المالية والمحاسبة، الجودة، السلامة والصحة المهنية، المبيعات وتطوير الأعمال، تقنية المعلومات، الإدارة والمساندة، المواقع والمعدات.

## الوظائف والبيانات
كل وظيفة تحتوي على: الهدف العام، المهام والمسؤوليات، المهام الدورية، الصلاحيات، المؤهلات، الخبرات والمهارات، مؤشرات الأداء KPI، ومتطلبات الالتزام والانضباط.

## المزايا
- بحث باسم الوظيفة أو القسم أو الرئيس المباشر.
- فلترة حسب القسم.
- صفحة تفصيلية لكل وظيفة.
- إضافة وتعديل وحذف.
- طباعة وحفظ PDF.
- **حفظ مركزي للتعديلات على Supabase**.
- تصدير واستيراد بيانات JSON.

## قاعدة البيانات
تم إنشاء جدول `public.job_descriptions` في مشروع Supabase المرتبط بالمشروع، مع تفعيل RLS وسياسات الوصول اللازمة للواجهة الحالية. تم التحقق من وجود **118 سجلًا و15 قسمًا**.

> ملاحظة تشغيلية: سياسات الكتابة الحالية تسمح بالقراءة والإضافة والتعديل والحذف عبر الواجهة بدون تسجيل دخول. إذا أردت إرسال النظام للموظفين مع منعهم من تعديل الأوصاف، فالخطوة التالية هي فصل صلاحيات العرض عن إدارة HR باستخدام Supabase Auth وRLS.
